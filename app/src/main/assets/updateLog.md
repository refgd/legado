# 更新日志

## 版本说明
此为「阅读R」的Rust版, Rust 版功能与普通版一致，兼容所有书源和配置。该版本使用 Rust 重写并优化了底层解析、网络等模块，部分场景下解析速度提升明显。例如「光遇源」600 余章目录解析，平均耗时由约 7 秒降低至约 1 秒。

目前 Rust 版仍处于测试阶段，欢迎反馈问题。
